# 2.1:
1. Наследование:
   Отсутствует. Все сущности не являются ни родителями ни детьми.
2. Композиция и владение:
   `Game` владеет жизненным циклом `Player`: экземпляр `Player` создаётся непосредственно внутри метода `Game.run()` для текущей игровой сессии.
3. Ассоциация / Внедрение зависимостей:
   Связи с `UI` реализованы через ассоциацию (использование). Экземпляр `UI` передаётся в конструкторы `Game` и `Player` извне (Dependency Injection), что исключает жёсткую привязку к консоли.
4. **Циклические зависимости:**
   Отсутствуют. Зависимости направлены в одну сторону: `Game -> Player -> UI` и `Game -> UI`. Класс `UI` не знает ни о ком.
